Introduction

The High Level Control System (HLCS) consists of components running on the Service Node (SN) the Subnet Service Nodes (SSN), and the Login or Front-End Nodes (LN or FEN). These components provide services to partition and boot the hardware so jobs can be submitted to them. They work in close coordination with the Low Level Control System (LLCS) to provide these services.
